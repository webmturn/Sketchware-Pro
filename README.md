# Wireless debugging UI previews

Native English UI captures for the upstream wireless debugging proposal.

- `wireless-discovery.png`: saved test device and a sample nearby pairing row.
- `wireless-pair.png`: six-digit pairing dialog, captured with an empty code field.
- `wireless-advanced.png`: manual connection fallback using documentation addresses.
- `wireless-logcat.png`: the existing Logcat reader showing sample remote logs.

These UI-test captures illustrate the interface and are not evidence of a completed
physical-device pairing/deployment test. The feature and validation guide live on
[codex/wireless-debugging-upstream](https://github.com/webmturn/Sketchware-Pro/tree/codex/wireless-debugging-upstream).

This separate branch hosts screenshots so image files do not enter the feature PR.
