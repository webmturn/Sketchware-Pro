# 双机无线调试

Sketchware Pro 在本机编译项目，通过无线 ADB 将调试 APK 安装并启动到另一部 Android 手机，同时读取应用日志。

## 首次添加设备

1. 两部手机连接同一 Wi-Fi，或由编程手机开热点、调试手机加入。
2. 调试手机需要 Android 11 或以上，在开发者选项开启“无线调试”，点击“使用配对码配对设备”，保持弹窗打开。
3. 编程手机打开项目，在**运行按钮旁的菜单 → 无线调试设备**进入连接页面。这是唯一的设置入口。
4. 页面自动显示附近设备。点击对应的“配对”条目，只输入六位配对码。
5. 配对成功后，自动发现连接端口、完成连接，并将当前项目设为远程运行。返回编辑器即可运行。

调试手机无需安装 Sketchware Pro 或接收助手，无需 root。编程手机沿用项目原有的最低系统版本。

## 再次连接

页面会记住已选设备的服务名称、可读取的设备 GUID / 序列号、型号和上次地址。再次打开页面时，会尝试自动连接已经选择的设备；“自动连接”也可以手动发起重连。

点击运行时会记录当时的设备身份，构建完成后重新发现其当前地址和端口。验证设备身份一致后才部署，避免地址重新分配后安装到另一台已配对手机。

页面保持可见时，会检查连接是否已断开或设备端口发生变化，并尝试重连；失败后留出重试间隔。点击“断开连接”会暂停本次页面会话的自动重连，直到再次主动连接或运行。

应用退到后台后不保证长期连接。下次打开连接页面或运行项目时会重新查找设备。

## 自动发现失败时

系统通过 mDNS 发布两种不同的服务：配对服务和运行连接服务。地址或端口变化后可通过这些服务重新获取信息。部分热点、访客 Wi-Fi 或厂商系统可能限制发现，仍需实机确认。

点击“重新搜索”可以重新开始发现；也可展开“高级连接”：

- 手动连接：填写无线调试**主页面**的 IP 地址和连接端口，再点击连接。
- 手动配对：填写 IP 地址，点击高级区域的“配对设备”，输入配对弹窗里的端口和六位码。
- 配对端口与连接端口不同。手动配对成功后也会尝试发现连接端口；找不到时会明确提示继续手动连接。

高级设置默认折叠。首次使用会尽量通过设备列表和配对码完成，不需要手动查找或抄写端口。此阶段未包含二维码配对。

## 运行与日志

- 本机运行仍为默认设置。连接设备成功后，当前项目可自动切换为远程运行，也可以关闭“在此设备上运行本项目”。
- 是否远程运行按项目保存；当前版本使用一台已选调试设备。
- 构建开始时记录目标身份。构建期间更换设置不会改变本次构建的部署目标。
- 使用 ADB 流式安装，不在调试手机留下临时 APK。安装失败会显示设备返回的原因，不自动卸载或降级应用，也不改为本机安装。
- 部分厂商系统仍可能需要在调试手机确认安装或开启相应开发者选项。
- 按远程设备当前用户和应用 UID 读取 main、system、crash 日志。启动前使用调试手机的时间记录日志起点，便于捕获启动后立即发生的崩溃；相同 UID 的其他进程也可能出现在日志里。
- 日志复用已有 Logcat 查看器，包括搜索、包名过滤、长按复制、清空和导出。连接页的“查看 Logcat 日志”或项目原有的 Logcat 入口均可进入；远程模式会在标题下标明来源。
- 最近 500 行日志保留在当前应用进程的内存，每行最多 2000 字符，打开查看器可回看已采集的日志。
- Logcat 菜单的“读取应用日志”可重新开始读取已安装应用的新日志，“停止日志”保留连接。连接页的“断开连接”关闭连接；操作进行中该按钮用于取消。取消时应用可能已在调试手机完成安装。

## 实现与验证

配对、认证和 TLS 使用固定版本的 LibADB Android 3.1.1 与 Conscrypt 2.5.3；设备发现使用 Android NsdManager，并与页面及连接操作的生命周期绑定。LibADB 自带的发现实现面向本机 ADB，因此跨设备发现独立实现。

配对身份保存在应用私有的 noBackupFilesDir 中，不随系统备份迁移。六位配对码仅用于当前配对，不保存到设置或日志。撤销调试手机上的配对授权后需要重新配对。

LibADB 的阻塞 Socket 不提供配对超时或 Socket 注入，因此使用仅绑定本机回环地址的透明转发器管理取消和超时；该转发器不终止 TLS。项目自带的 apksigner JAR 含桌面 Conscrypt 类，prepareAndroidApkSignerJar 任务构建去重后的副本，原始 JAR 保持不变。

自动验证覆盖：APK 二进制传输与安装失败、设备选择与身份校验、服务实例及地址变化、配对端口与连接端口区分、实际 mDNS 发布与解析、发现的生命周期、只填写配对码的界面、高级连接入口，以及复用 Logcat 后的搜索、清空和增量日志回放。

本次验证通过 249 项单元测试与 6 项实机仪器测试，包括已配对调试手机变更连接端口后，自动发现新端口并按原设备身份完成重连。配对弹窗的界面测试使用固定发现数据；mDNS 更新与生命周期由独立实机测试覆盖。

双机验收还需检查：首次配对后自动连接、不同 Wi-Fi / 热点环境、系统拒绝安装、签名冲突、取消传输、关闭无线调试和启动即崩溃。
